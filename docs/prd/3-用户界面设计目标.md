# 3. 用户界面设计目标

### 3.1 整体UX愿景

提供简洁直观的嵌入式设备界面，以最少的操作步骤完成烧录任务。界面风格应体现专业工具属性，信息展示清晰，操作反馈及时。

### 3.2 关键交互范式

- **状态导向**：主界面始终显示当前设备状态（空闲/检测中/烧录中/完成/错误）
- **即时反馈**：每个操作步骤提供实时进度和结果反馈
- **容错设计**：关键操作需确认，误操作可恢复
- **最小化输入**：利用自动检测减少手动配置

### 3.3 核心屏幕与视图

| 屏幕 | 功能 | 优先级 |
|------|------|--------|
| 主状态屏 | 显示烧录器状态、目标MCU信息、当前固件 | P0 |
| 固件列表屏 | 浏览SD卡固件文件，选择待烧录固件 | P1 |
| 烧录进度屏 | 显示烧录进度条、当前步骤、耗时 | P0 |
| 设备信息屏 | 详细显示目标MCU型号、Flash/EEPROM大小、UID | P1 |
| 设置屏 | 系统配置（波特率、超时时间等） | P2 |
| 错误详情屏 | 显示错误码、错误描述、建议操作 | P0 |

### 3.4 可访问性

- 基础可访问性：高对比度显示，适合工业环境光照条件
- 不强制要求WCAG标准（嵌入式设备限制）

### 3.5 品牌与风格

- 工业风格：深色背景 + 高亮状态色
- 状态色定义：
  - 成功/正常：绿色
  - 进行中：蓝色
  - 警告：黄色
  - 错误：红色
- 字体：清晰的等宽字体，适合显示HEX数据和技术参数

### 3.6 目标设备与平台

- 主显示：复用现有工程 LCD 驱动（`Src/lcd.c` + `Inc/lcd.h`），驱动已完成调试，可直接调用，本项目不重新开发 LCD 驱动层，仅负责基于该驱动实现显示逻辑，并确保 LCD 显示内容与串口调试输出保持一致
- 输入：物理按键（4-6键）
- 不涉及Web/Mobile平台
