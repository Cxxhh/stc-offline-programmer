# 5. 史诗列表

### Epic 1: 基础架构与串口通信
建立项目基础架构，实现与STC目标MCU的串口通信能力，完成环形缓冲区和HAL层实现。

### Epic 2: ISP握手协议与MCU识别
实现STC ISP握手协议，完成目标MCU自动识别功能，建立协议解析框架。

### Epic 3: 擦除与编程功能
实现Flash擦除和代码烧录功能，完成数据校验机制，形成最小可用烧录器。

### Epic 4: 用户界面与固件管理
实现LCD显示界面和按键交互，集成SD卡固件存储，提供完整的用户操作体验。

### Epic 5: 高级功能与优化
实现EEPROM烧录、RC校准、批量模式等高级功能，优化性能和稳定性。
