## 变更记录

### 变更1：波特率描述一致性修正

**问题描述**：
- PRD `2-需求.md` FR7 规定："数据传输阶段协商高速（最高230400bps）"
- 但 PRD `6-史诗详情.md` Story 2.4 验收标准仅列出"115200/57600/38400等常用波特率"，遗漏了最高支持的230400bps

**修正措施**：
- **修改文件**：`docs/prd/6-史诗详情.md`
- **修改内容**：Story 2.4 验收标准第3条
  - 原文：`支持协商至115200/57600/38400等常用波特率`
  - 改为：`支持协商至230400/115200/57600/38400等常用波特率（最高230400bps）`

**关联修改**：
- **修改文件**：`docs/architecture/6-依赖注入与解耦示例.md`
- **修改内容**：代码示例中 `target_baudrate = 115200` 添加注释说明
  - 改为：`target_baudrate = 115200  /* 默认值，系统支持最高230400bps */`

---

### 变更2：Log和RingBuffer模块层级位置修正

**问题描述**：
- PRD `4-技术假设.md` 架构图显示 `Log` 和 `RingBuf` 位于 **Middlewares层**
- 架构文档 `1-架构概览.md` 架构图同样显示二者在 **Middlewares层**
- 但架构文档 `1-架构概览.md` 目录结构却将它们放在 **Service层**：
  ```
  ├── Service/
  │   ├── log.c/h          # 错误位置
  │   └── ringbuffer.c/h   # 错误位置
  ```

**修正措施**：
- **修改文件**：`docs/architecture/1-架构概览.md`
- **修改内容**：调整目录结构，将 `log.c/h` 和 `ringbuffer.c/h` 移至 Middlewares层
  ```
  ├── Middlewares/
  │   ├── FatFs/
  │   ├── Log/
  │   │   └── log.c/h
  │   ├── RingBuffer/
  │   │   └── ringbuffer.c/h
  │   └── stc_isp/
  ```

**影响分析**：
- 此变更影响实际代码目录结构规划
- 开发时需将已有的 `ringbuffer.c/h` 和 `log.c/h` 迁移至 `Middlewares/` 目录下

### 变更4：LCD驱动复用现有实现

**变更日期**：2025-12-10

**问题描述**：
- 变更3错误假设需要新开发 ST7735 LCD 驱动
- 实际情况：项目中已存在完整可用的 LCD 驱动（`Src/lcd.c` + `Inc/lcd.h`）
- 该驱动为 CT117E 嵌入式竞赛板 LCD 驱动，已完成调试验证，可直接调用
- 本项目不应重新开发 LCD 驱动层，仅需基于现有驱动实现显示逻辑

**修正措施**：
- **修改文件**：`docs/prd/3-用户界面设计目标.md`
- **修改内容**：3.6节"目标设备与平台"
  - 原文：`主显示：ST7735 TFT LCD显示屏（128×160像素，RGB565色深）`
  - 改为：`主显示：复用现有工程 LCD 驱动（Src/lcd.c + Inc/lcd.h），驱动已完成调试，可直接调用，本项目不重新开发 LCD 驱动层，仅负责基于该驱动实现显示逻辑，并确保 LCD 显示内容与串口调试输出保持一致`

- **修改文件**：`docs/prd.md`
- **修改内容**：3.6节同步更新

- **修改文件**：`docs/architecture/1-架构概览.md` 和 `docs/architecture.md`
- **修改内容**：Display 目录结构
  - 原文：`bsp_lcd_st7735.c/h  # ST7735 LCD驱动`
  - 改为：`bsp_display.c/h  # 显示设备管理器（复用现有 Src/lcd.c 驱动）`

## 变更影响总结

| 变更项 | 影响范围 | 开发影响 |
|--------|----------|----------|
| 波特率描述 | 验收标准 | 需实现230400bps支持 |

## 后续建议

1. **代码迁移**：开发阶段需将 `log.c/h` 和 `ringbuffer.c/h` 从 Service 目录迁移至 Middlewares 目录
2. **波特率验证**：在Story 2.4实施时需确保230400bps的稳定性测试
3. **显示逻辑开发**：基于现有 `lcd.c` 接口开发 `bsp_display.c/h` 封装层，实现 UI 显示逻辑
4. **输出一致性**：确保 LCD 显示内容与串口调试输出保持同步一致
