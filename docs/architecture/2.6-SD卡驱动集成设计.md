## 硬件配置

### 引脚分配

| 信号 | 引脚 | GPIO模式 | 复用功能 |
|------|------|----------|----------|
| SPI1_SCK | PA5 | AF_PP | AF5 |
| SPI1_MISO | PA6 | AF_PP | AF5 |
| SPI1_MOSI | PA7 | AF_PP | AF5 |
| SD_CS | PB10 | 推挽输出 | GPIO |

### DMA通道配置

| 通道 | 外设 | 方向 | 优先级 |
|------|------|------|--------|
| DMA1_Channel1 | SPI1_RX | 外设→内存 | 高 |
| DMA1_Channel2 | SPI1_TX | 内存→外设 | 高 |

### 中断配置

中断处理已在 `Src/stm32g4xx_it.c` 中实现：

```c
void DMA1_Channel1_IRQHandler(void)  // SPI1 RX DMA
{
    if (LL_DMA_IsActiveFlag_TC1(DMA1)) {
        LL_DMA_ClearFlag_TC1(DMA1);
        bsp_spi_dma_rx_complete_callback();
    }
    // 错误处理...
}

void DMA1_Channel2_IRQHandler(void)  // SPI1 TX DMA
{
    if (LL_DMA_IsActiveFlag_TC2(DMA1)) {
        LL_DMA_ClearFlag_TC2(DMA1);
        bsp_spi_dma_tx_complete_callback();
    }
    // 错误处理...
}
```

## 使用示例

### 基础读写

```c
#include "bsp_sdcard.h"
#include "ff.h"

FATFS fs;
FIL   file;
UINT  br, bw;

// 初始化SD卡
if (bsp_sdcard_init() != BSP_SDCARD_OK) {
    // 错误处理
}

// 挂载文件系统
if (f_mount(&fs, "0:", 1) != FR_OK) {
    // 错误处理
}

// 读取固件文件
if (f_open(&file, "0:firmware.bin", FA_READ) == FR_OK) {
    uint8_t buffer[512];
    while (f_read(&file, buffer, sizeof(buffer), &br) == FR_OK && br > 0) {
        // 处理数据
    }
    f_close(&file);
}
```

### 多设备共享SPI

```c
// SD卡和W25Qxx共享SPI1时的互斥访问
if (bsp_spi_dma_lock(BSP_SPI_DMA_DEVICE_SD_CARD)) {
    bsp_sdcard_select();
    // 执行SD卡操作
    bsp_sdcard_deselect();
    bsp_spi_dma_unlock(BSP_SPI_DMA_DEVICE_SD_CARD);
}
```
