# 2.5 LCD 驱动集成设计

## 2.5.1 重要前提

本项目已存在**稳定可用**的 LCD 驱动模块：

| 项目 | 说明 |
|------|------|
| **源码位置** | `Src/lcd.c` |
| **头文件** | `Inc/lcd.h` |
| **验证状态** | ✅ 已在现有工程中验证通过 |
| **设计策略** | 复用现有驱动，**不重新实现底层** |

## 2.5.2 架构定位

### 层级映射

```
┌─────────────────────────────────────────────────────────────────────────┐
│                              APP Layer (L4)                             │
│                         app_ui.c / screen_xxx.c                         │
│                         页面逻辑 / UI 状态机                              │
├─────────────────────────────────────────────────────────────────────────┤
│                         Display Service (L3)                            │
│                      Service/display/disp_service.c                     │
│                 高级绘图 / 界面组件 / 文本渲染增强                          │
├─────────────────────────────────────────────────────────────────────────┤
│                         BSP Display (L1)                                │
│                      BSP/Display/bsp_display.c                          │
│              display_dev_t 接口实现 → 封装调用 LCD_xxx()                  │
├─────────────────────────────────────────────────────────────────────────┤
│                      LCD Driver (L0 - 现有驱动)                          │
│                         Src/lcd.c + Inc/lcd.h                           │
│                      底层硬件操作 / 寄存器读写                             │
│                         ⚠️ 不修改，直接复用                               │
└─────────────────────────────────────────────────────────────────────────┘
```

### 调用链路

```
APP Layer (页面逻辑)
     │
     │  调用
     ▼
Display Service (disp_service_xxx)
     │
     │  调用
     ▼
BSP Display (display_dev_t 接口)
     │
     │  内部调用
     ▼
LCD Driver (LCD_xxx 函数)  ← 现有驱动，不修改
     │
     │  硬件操作
     ▼
LCD 硬件 (FSMC/GPIO)
```

|------|------|

| `LCD_DisplayOff()` | 关闭显示 |

### 颜色设置

| 函数 | 功能 |
|------|------|
| `LCD_SetTextColor(color)` | 设置前景色（文字/线条） |
| `LCD_SetBackColor(color)` | 设置背景色 |

### 清屏 / 文本

| 函数 | 功能 |
|------|------|
| `LCD_Clear(color)` | 全屏清屏 |
| `LCD_ClearLine(line)` | 清除指定行 |
| `LCD_DisplayStringLine(line, str)` | 在指定行显示字符串（最多 20 字符） |
| `LCD_DisplayChar(line, col, ascii)` | 显示单个字符 |

### 图形绘制

| 函数 | 功能 |
|------|------|
| `LCD_DrawLine(x, y, len, dir)` | 绘制直线（水平/垂直） |

| `LCD_DrawCircle(x, y, r)` | 绘制圆 |
| `LCD_DrawPicture(picture)` | 绘制全屏图片 |

### 底层操作

| 函数 | 功能 |
|------|------|
| `LCD_SetCursor(x, y)` | 设置光标位置 |
| `LCD_SetDisplayWindow(x, y, h, w)` | 设置显示窗口 |
| `LCD_WriteRAM_Prepare()` | 准备写 GRAM |
| `LCD_WriteRAM(color)` | 写入像素 |
| `LCD_ReadRAM()` | 读取像素 |

## 2.5.4 BSP Display 封装设计

### 文件结构

```
BSP/
└── Display/
    ├── bsp_display.h        # display_dev_t 接口声明
    └── bsp_display.c        # 封装 LCD_xxx() 实现
```

### 接口实现映射

| display_dev_t 接口 | 底层 LCD_xxx 调用 |
|-------------------|------------------|
| `open()` | `LCD_Init()` |
| `close()` | `LCD_DisplayOff()` |
| `clear(color)` | `LCD_Clear(color)` |
| `draw_pixel(x,y,c)` | `LCD_SetCursor()` + `LCD_WriteRAM_Prepare()` + `LCD_WriteRAM()` |
| `draw_hline(x,y,len,c)` | `LCD_SetTextColor()` + `LCD_DrawLine(x,y,len,Horizontal)` |
| `draw_vline(x,y,len,c)` | `LCD_SetTextColor()` + `LCD_DrawLine(x,y,len,Vertical)` |
| `fill_rect(x,y,w,h,c)` | 循环调用 `LCD_DrawLine()` 或窗口填充 |
| `draw_string(...)` | `LCD_SetTextColor()` + `LCD_SetBackColor()` + `LCD_DisplayStringLine()` |
| `set_window(...)` | `LCD_SetDisplayWindow()` |

### bsp_display.h 设计

```c
/* BSP/Display/bsp_display.h */

#ifndef __BSP_DISPLAY_H__
#define __BSP_DISPLAY_H__

#include "BSP/Interface/dev_display.h"

/* LCD 屏幕参数 */
#define BSP_LCD_WIDTH           320
#define BSP_LCD_HEIGHT          240
#define BSP_LCD_CHAR_WIDTH      16
#define BSP_LCD_CHAR_HEIGHT     24
#define BSP_LCD_LINE_COUNT      10
#define BSP_LCD_CHARS_PER_LINE  20

/* 行号宏（兼容现有驱动） */
#define BSP_LCD_LINE(n)         ((n) * BSP_LCD_CHAR_HEIGHT)

/* 创建 LCD 显示设备实例 */
display_dev_t *bsp_display_create(const char *name);

/* 获取默认 LCD 设备 */
display_dev_t *bsp_display_get_default(void);

#endif /* __BSP_DISPLAY_H__ */
```

### bsp_display.c 实现框架

```c
/* BSP/Display/bsp_display.c */

#include "bsp_display.h"
#include "lcd.h"  /* 现有 LCD 驱动头文件 */

/* 私有变量 */
static display_dev_t s_lcd_dev;
static bool s_is_initialized = false;

/* ==================== 内部函数（封装 LCD_xxx） ==================== */

static dev_status_t _lcd_open(dev_base_t *dev)
{
    LCD_Init();
    LCD_Clear(Black);
    s_lcd_dev.base.is_open = true;
    return DEV_OK;
}

static dev_status_t _lcd_close(dev_base_t *dev)
{
    LCD_DisplayOff();
    s_lcd_dev.base.is_open = false;
    return DEV_OK;
}

static dev_status_t _lcd_clear(display_dev_t *dev, color_t color)
{
    LCD_Clear(color);
    return DEV_OK;
}

static dev_status_t _lcd_draw_pixel(display_dev_t *dev, uint16_t x, uint16_t y, color_t color)
{
    /* 坐标转换：display_dev 使用标准坐标系 (0,0) 左上角 */
    LCD_SetCursor(y, BSP_LCD_WIDTH - 1 - x);
    LCD_WriteRAM_Prepare();
    LCD_WriteRAM(color);
    return DEV_OK;
}

static dev_status_t _lcd_draw_hline(display_dev_t *dev, uint16_t x, uint16_t y, uint16_t len, color_t color)
{
    LCD_SetTextColor(color);
    LCD_DrawLine(y, BSP_LCD_WIDTH - 1 - x, len, Horizontal);
    return DEV_OK;
}

static dev_status_t _lcd_draw_vline(display_dev_t *dev, uint16_t x, uint16_t y, uint16_t len, color_t color)
{
    LCD_SetTextColor(color);
    LCD_DrawLine(y, BSP_LCD_WIDTH - 1 - x, len, Vertical);
    return DEV_OK;
}

static dev_status_t _lcd_fill_rect(display_dev_t *dev, uint16_t x, uint16_t y, uint16_t w, uint16_t h, color_t color)
{
    /* 使用窗口模式高效填充 */
    LCD_SetTextColor(color);
    for (uint16_t i = 0; i < h; i++) {
        LCD_DrawLine(y + i, BSP_LCD_WIDTH - 1 - x, w, Horizontal);
    }
    return DEV_OK;
}

static dev_status_t _lcd_draw_string(display_dev_t *dev, uint16_t x, uint16_t y, 
                                      const char *str, const font_t *font, 
                                      color_t fg, color_t bg)
{
    /* 使用现有字符显示函数 */
    LCD_SetTextColor(fg);
    LCD_SetBackColor(bg);
    
    /* 计算行号（y 坐标需转换为 Line0~Line9） */
    uint8_t line = y / BSP_LCD_CHAR_HEIGHT * BSP_LCD_CHAR_HEIGHT;
    LCD_DisplayStringLine(line, (u8 *)str);
    
    return DEV_OK;
}

/* ==================== 公共接口 ==================== */

display_dev_t *bsp_display_create(const char *name)
{
    if (s_is_initialized) {
        return &s_lcd_dev;
    }
    
    /* 初始化设备结构 */
    s_lcd_dev.base.name = name;
    s_lcd_dev.base.type = DEV_TYPE_DISPLAY;
    s_lcd_dev.base.is_open = false;
    s_lcd_dev.base.priv_data = NULL;
    
    /* 绑定基类操作 */
    s_lcd_dev.base.open = _lcd_open;
    s_lcd_dev.base.close = _lcd_close;
    s_lcd_dev.base.ioctl = NULL;  /* 可后续扩展 */
    
    /* 绑定显示操作 */
    s_lcd_dev.width = BSP_LCD_WIDTH;
    s_lcd_dev.height = BSP_LCD_HEIGHT;
    s_lcd_dev.rotation = 0;
    
    s_lcd_dev.clear = _lcd_clear;
    s_lcd_dev.draw_pixel = _lcd_draw_pixel;
    s_lcd_dev.draw_hline = _lcd_draw_hline;
    s_lcd_dev.draw_vline = _lcd_draw_vline;
    s_lcd_dev.fill_rect = _lcd_fill_rect;
    s_lcd_dev.draw_string = _lcd_draw_string;
    
    /* 可选接口（暂不实现） */
    s_lcd_dev.draw_char = NULL;
    s_lcd_dev.draw_bitmap = NULL;
    s_lcd_dev.set_window = NULL;
    s_lcd_dev.write_data = NULL;
    s_lcd_dev.set_backlight = NULL;
    s_lcd_dev.set_rotation = NULL;
    
    s_is_initialized = true;
    return &s_lcd_dev;
}

display_dev_t *bsp_display_get_default(void)
{
    if (!s_is_initialized) {
        return bsp_display_create("LCD");
    }
    return &s_lcd_dev;
}
```

## 2.5.5 Display Service 层设计

### 职责定位

Display Service 层位于 BSP 和 APP 之间，提供：

1. **高级绘图函数**：进度条、按钮、列表等 UI 组件
2. **文本渲染增强**：多行文本、自动换行、中文支持
3. **界面布局管理**：区域划分、坐标转换
4. **双缓冲支持**：减少闪烁（可选）

### 文件结构

```
Service/
└── display/
    ├── disp_service.h       # 显示服务接口
    ├── disp_service.c       # 显示服务实现
    ├── disp_widget.h        # UI 组件定义
    └── disp_widget.c        # UI 组件实现
```

### disp_service.h 设计

```c
/* Service/display/disp_service.h */

#ifndef __DISP_SERVICE_H__
#define __DISP_SERVICE_H__

#include <stdint.h>
#include <stdbool.h>
#include "BSP/Interface/dev_display.h"

/* ==================== 显示服务状态 ==================== */

typedef enum {
    DISP_SVC_IDLE = 0,
    DISP_SVC_INIT,
    DISP_SVC_RUNNING,
    DISP_SVC_ERROR
} disp_service_state_enum;

/* ==================== 服务初始化 ==================== */

/* 初始化显示服务（注入显示设备） */

/* 获取服务状态 */
disp_service_state_enum disp_service_get_state(void);

/* ==================== 文本显示增强 ==================== */

/* 在指定行显示文本（兼容现有 Line0~Line9） */
void disp_show_line(uint8_t line, const char *text, uint16_t fg, uint16_t bg);

void disp_show_status(const char *status, uint16_t fg, uint16_t bg);

/* 显示进度条 */
void disp_show_progress(uint8_t line, uint8_t percent, uint16_t fg, uint16_t bg);

/* 显示消息框 */
void disp_show_message(const char *title, const char *msg, uint16_t fg, uint16_t bg);

/* ==================== 屏幕管理 ==================== */

/* 清屏 */
void disp_clear(uint16_t color);

/* 刷新显示（预留双缓冲） */
```

## 2.5.6 使用示例

### 系统初始化

```c
/* main.c 或 app_init.c */

#include "BSP/Display/bsp_display.h"
#include "Service/display/disp_service.h"

void system_init(void)
{
    /* 创建并注册 LCD 设备 */
    display_dev_t *lcd = bsp_display_create("LCD");
    lcd->base.open(&lcd->base);  /* 调用 LCD_Init() */
    
    /* 初始化显示服务 */
    disp_service_init(lcd);
    
    /* 显示启动界面 */
    disp_clear(Black);
    disp_show_title("STC Programmer", Yellow, Blue);
    disp_show_line(4, "System Ready", Green, Black);
}
```

### APP 层使用

```c
/* app_ui.c */

#include "Service/display/disp_service.h"

void app_ui_show_progress(uint8_t percent)
{
    disp_show_line(3, "Programming...", White, Black);
    disp_show_progress(5, percent, Green, Black);
    disp_show_line_fmt(7, White, Black, "Progress: %3d%%", percent);
}

void app_ui_show_result(bool success, const char *msg)
{
    if (success) {
        disp_show_message("Success", msg, Green, Black);
    } else {
        disp_show_message("Error", msg, Red, Black);
    }
}
```

## 2.5.7 关键设计原则

### ✅ 遵循原则

| 原则 | 实现 |
|------|------|
| **不修改原驱动** | `Src/lcd.c` 保持不变，所有适配在 `bsp_display.c` |
| **单向依赖** | Service → BSP → LCD Driver，禁止反向 |
| **接口隔离** | 上层只使用 `display_dev_t` 和 `disp_service_xxx()` |
| **可替换性** | 如需更换 LCD，只需修改 `bsp_display.c` 的映射 |

### ⚠️ 注意事项

1. **坐标系差异**：现有 LCD 驱动的坐标系可能与标准不同，`bsp_display.c` 内部做转换
2. **字体限制**：现有驱动仅支持 16×24 ASCII 字体，中文需另外实现
3. **颜色格式**：RGB565，与 `display_dev_t` 的 `color_t` 一致
