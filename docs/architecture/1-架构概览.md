# 1. 架构概览

### 1.1 设计原则

| 原则 | 描述 | 实现方式 |
|------|------|----------|
| **接口抽象** | 所有硬件操作通过统一接口访问 | 设备操作结构体 + 函数指针 |
| **依赖注入** | 上层模块不直接依赖具体实现 | 运行时注册设备实例 |
| **单向依赖** | 只允许上层调用下层 | 严格分层 + 编译检查 |
| **零耦合移植** | 更换平台只需重写Port层 | Port/Driver分离 |
| **统一IO模型** | 串口/LCD/存储使用相同操作范式 | 通用设备接口 |

### 1.4 LCD 驱动集成说明

> ⚠️ **重要前提**：项目已存在稳定可用的 LCD 驱动模块（`Src/lcd.c` + `Inc/lcd.h`），
> 已在现有工程中验证通过。本项目**不重新设计/实现底层 LCD 驱动**。

**架构定位**：
```
APP Layer (app_ui.c)
     │ 调用 disp_service_xxx()
     ▼
Service Layer (disp_service.c)         ← 高级显示服务
     │ 调用 display_dev_t 接口
     ▼
BSP Layer (bsp_display.c)              ← 封装层
     │ 内部调用 LCD_xxx()
     ▼
现有驱动 (Src/lcd.c)                    ← L0 底层驱动，不修改
     │
     ▼
LCD 硬件
```

详细设计见：[2.5-LCD驱动集成设计.md](2.5-LCD驱动集成设计.md)

### 1.5 SD卡驱动集成说明

> ✅ **已完成**：项目已存在完整的SD卡驱动库（`BSP/bsp_sdcard.c/h` + `BSP/bsp_spi.c/h`），
> 支持SPI模式SD卡读写和FatFs文件系统，已验证通过。

**现有模块**：
| 文件 | 说明 |
|------|------|
| `BSP/bsp_common.h` | BSP层公共定义和类型 |
| `BSP/bsp_spi.c/h` | SPI DMA总线管理器，支持多设备共享 |
| `BSP/bsp_sdcard.c/h` | SD卡硬件驱动（SPI模式） |
| `FatFS/src/` | FatFs文件系统中间件 |

**架构定位**：
```
APP Layer (app_main.c)
     │ 调用 file_mgr_xxx()
     ▼
Service Layer (file_manager.c)         ← 文件管理服务
     │ 调用 FatFs API
     ▼
Middlewares Layer (FatFs)               ← 文件系统中间件
     │ 调用 diskio 接口
     ▼
BSP Layer (bsp_sdcard.c)               ← SD卡驱动（已实现）
     │ 调用 bsp_spi_xxx()
     ▼
BSP Layer (bsp_spi.c)                  ← SPI DMA管理器（已实现）
     │
     ▼
SD卡硬件 (SPI1)
```

**硬件配置**：
| 信号 | 引脚 | 说明 |
|------|------|------|
| SPI1_SCK | PA5 | SPI时钟 |
| SPI1_MISO | PA6 | SPI数据输入 |
| SPI1_MOSI | PA7 | SPI数据输出 |
| SD_CS | PB10 | SD卡片选 |

详细设计见：[2.6-SD卡驱动集成设计.md](2.6-SD卡驱动集成设计.md)

| `Src/stm32g4xx_it.c` | USART2中断服务 `USART2_IRQHandler()` | ✅ 已完成 |
| `BSP/Serial/bsp_stc_uart.c/h` | STC串口BSP封装 | ⏳ 待实现 |

**硬件配置**：
| 参数 | 值 | 说明 |
|------|-----|------|
| 串口 | USART2 | STC通信专用 |
| TX引脚 | PA2 | 发送 |
| RX引脚 | PA3 | 接收（已配置上拉） |
| 默认波特率 | 2400bps | STC握手波特率 |
| 数据位 | 9位 | 8数据+1校验位 |
| 校验位 | 偶校验(EVEN) | STC8系列要求 |
| 停止位 | 1位 | - |

**架构定位**：
```
Service Layer (stc_isp_protocol.c)     ← ISP协议层
     │ 调用 serial_dev_t 接口
     ▼

     │ 调用现有初始化 + 中断回调
     ▼
HAL Layer (Src/usart.c)                ← CubeMX生成代码（已完成）
     │
     ▼
USART2 硬件
```
